# Звіт перевірки

## Методика

Автоматизовані перевірки описані у `test_firewall.py` і працюють із тимчасовими файлами. `dynamic_demo.py` запускає TCP та UDP echo-служби лише на вільних портах `127.0.0.1`, змінює правила в процесі роботи, перевіряє блокування, повторне дозволення, конфлікти та JSONL-події. Скрипти не змінюють системні правила мережі.

## Результати

У попередньому середовищі Python був відсутній. Після виправлень повторна спроба `py -3.13 --version`, компіляції файлів, pytest та `dynamic_demo.py` завершилася повідомленням `No installed Python found!` для кожної команди. Тому нові зміни не мають підтверджених результатів запуску.

| Перевірка | Очікуване | Фактичне |
| --- | --- | --- |
| Синтаксис Python | Усі файли компілюються | Не запускалося |
| pytest | Тести правил, конфігурації, журналу і конкурентного доступу проходять | Не запускалося |
| TCP/UDP localhost | Allow/deny через реальні сокети | Не запускалося |
| Динамічне оновлення | Наступне з'єднання/пакет бачить нове правило | Не запускалося |
| Аналіз конфліктів | Знайдено дублікат та перекриття | Не запускалося |
| Експорт | Створюються Markdown та CSV | Не запускалося |
